Not sure which Mac you have? Choose Apple menu → About This Mac: a “Chip” line means Apple silicon (M1 or later), a “Processor” line means Intel.

The first time you open it

Strandivo isn't signed by Apple or Microsoft yet, so each warns you the first time you open it.

Mac

Open the downloaded file and drag Strandivo into Applications. Open it once; when macOS says it can't check the app, click Done. Then go to System Settings → Privacy & Security, scroll down and click Open Anyway. If macOS says instead that the app “is damaged”, run this in Terminal once:

xattr -dr com.apple.quarantine "/Applications/Strandivo.app"

Windows

If SmartScreen shows “Windows protected your PC”, click More info, then Run anyway. Strandivo installs for you alone, without asking for an administrator.

Linux

Install the .deb on Debian, Ubuntu and their relatives. Elsewhere, make the AppImage executable (chmod +x Strandivo_amd64.AppImage) and run it. Strandivo needs WebKitGTK 4.1, which current Ubuntu, Debian and Fedora releases include.

What it needs

  • macOS 11 (Big Sur) or later, on Apple silicon or Intel.
  • 64-bit Windows 10 or 11.
  • 64-bit Linux with WebKitGTK 4.1.

First launch

Strandivo isn't code-signed by Apple or Microsoft yet, so macOS and Windows show a security prompt the first time you open it.

Mac

Open the downloaded disk image and drag Strandivo into Applications. Open it once; when macOS says it can't verify the app, click Done. Then open System Settings → Privacy & Security, scroll down and click Open Anyway. If macOS instead says the app “is damaged”, run this in Terminal once:

xattr -dr com.apple.quarantine "/Applications/Strandivo.app"

Windows

If SmartScreen shows “Windows protected your PC”, click More info, then Run anyway. Strandivo installs for your user account without needing administrator rights.

Linux

Install the .deb on Debian, Ubuntu and derivatives, or make the AppImage executable (chmod +x Strandivo_Linux.AppImage) and run it. Strandivo needs WebKitGTK 4.1, which current Ubuntu, Debian and Fedora releases include.

System requirements

  • macOS 11 (Big Sur) or later, on Apple silicon or Intel.
  • 64-bit Windows 10 or 11.
  • 64-bit Linux with WebKitGTK 4.1.

Checking a download

From Strandivo 0.4.0, GitHub keeps a signed record of the source code and build that made each installer. To check that a file is unchanged since that build, run this with the GitHub CLI, signed in to any GitHub account:

gh attestation verify Strandivo_Windows_setup.exe --repo Mateusz-Jaskolowski/Strandivo

Older versions and source code are on GitHub Releases.
